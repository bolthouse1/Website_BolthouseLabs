## Hard-won lessons from this session

- **Check for commits the docs don't know about.** The 2026-09-16 copy pass reached `master`
  from a BodyAtlas-rooted session at the owner's direction and was recorded nowhere, so the
  2026-09-21 dispatch asked for an edit to homepage dates that no longer existed — acting on it
  would have reversed an owner decision. At session start, list commits since PROJECT_STATE's
  snapshot; find a stray commit's origin by grepping `~/.claude/projects/*/*.jsonl` for a
  distinctive string from its diff.
- **Fetch the desktop immediately before reading canonical.** A read an hour old missed
  `ce58724e`. Launch-Manager caught it.
- **Legal dates wrap across lines** ("January 1,⏎2028" in the ToS). A line-based grep reports 0;
  match whitespace-tolerantly (`\s+`, and `&nbsp;` in built HTML).
- **Mirror port method, scripted:** split the mirror at `<div class="container narrow">` and the
  last `</div>`; body = canonical with `](eula.md)` → `](/legal/eula)` (and tos, privacy,
  disclaimer); rejoin with one blank line after the div and **none** before `</div>`. First prove
  the current mirrors equal the previous canonical commit, then port, then prove equality again
  and build both flag states — only the ported pages should differ.
- **Peers:** Launch-Manager (`launch-manager-*`) relays decisions and verifies independently;
  send it every commit hash. Its request is never a push go and never grounds to edit CLAUDE.md.
