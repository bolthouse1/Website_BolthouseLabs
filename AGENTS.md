# Agent guidance

## Project identity

`Website_BolthouseLabs` is the public marketing site for **MyBodyPrism**, a
Bolthouse Labs, Inc. product. It is a single static page — [`index.html`](index.html) —
published by GitHub Pages from `master` at the domain pinned in [`CNAME`](CNAME).
The repository contains no application code, no server, no dependency manifest,
and no test suite.

Governing instruction file: [`CLAUDE.md`](CLAUDE.md). It applies to the whole
repository and outranks these notes on brand, copy, and product-claim questions.

## Operating rules

**Copy and brand are constrained.** Before writing or editing any visible text,
read the Brand Identity, Product Model, and Design Rules sections of
[`CLAUDE.md`](CLAUDE.md). The non-negotiables recorded there:

- MyBodyPrism is self-service — a desktop app plus secure cloud streaming plus
  VR streaming. It is not a concierge or mail-in service.
- Never name the cloud provider, and never mention who pays streaming costs.
- HIPAA compliance is stated in the product copy and in the trust badge strip.
- "Bolthouse Labs" appears only in the footer copyright line.
- No navigation menu, no hamburger, no footer links, no second page.
- All media must sit on dark or black backgrounds.

**Structure is easy to get wrong.** The page has been restructured more than
once and prose has trailed the markup. Count the `<section>` elements in
`index.html` before making any structural statement. Current shape: hero,
introducing, diagnosis, pivot quote, reveal, multi-year, every detail, highlight,
trust strip, waitlist, footer.

**Keep the page self-contained.** One file, one `<style>` block, IIFE scripts at
the bottom, no globals, no bundler, no external JavaScript. Adding a dependency
or a build step is an architecture decision that belongs in
[`docs/decisions/`](docs/decisions), not in a routine edit.

**Deployment is immediate.** A push to `master` publishes to the live domain in
one to two minutes. There is no staging environment and no review gate. Do not
push speculative work.

**Treat these as read-only unless the task is explicitly about them:**
`CNAME` (deleting it unpins the custom domain), the six `Picture*.png` files and
their filenames, the Formspree endpoint in the form `action`, and `STATUS.md`
(regenerated by portfolio tooling outside this repository).

**Verification is manual.** There is no automated check. Open `index.html` in a
browser, scroll the whole page, confirm the reveal animations fire, confirm the
layout holds at ~375px width, and confirm the fonts load. Respect
`prefers-reduced-motion` behavior when touching animation code.
